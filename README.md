# GlowAutoRestart

Высокопроизводительный плагин для автоматического перезапуска сервера Minecraft по расписанию и с обратным отсчётом. Поддерживает Paper, Purpur и Folia на платформе Java 21.

## Возможности

- **Режимы расписания**:
  - `FIXED_TIMES` — перезапуск в заданные часы (например, `00:00`, `06:00`, `12:00`, `18:00`) с поддержкой часовых поясов.
  - `INTERVAL` — перезапуск через равные промежутки времени (например, каждые 6 часов).
- **Визуальные оповещения**:
  - Заголовки на экране (Title и Subtitle) с кастомизацией времени показа.
  - Сообщения в Actionbar.
  - Сообщения в чат.
  - Звуковые эффекты на вехах отсчёта.
  - Динамический BossBar с прогрессом и кастомными стилями.
- **Безопасный перезапуск**:
  - Выполнение команд перед перезагрузкой (автоматическое сохранение миров `save-all`).
  - Мягкий кик игроков с настраиваемой причиной перед остановкой сервера.
  - Поддержка Folia (асинхронные и глобальные шедулеры).

## Команды и права

| Команда | Описание | Право |
|---|---|---|
| `/gar time` | Показать оставшееся время до рестарта | `glowautorestart.use` |
| `/gar start <время>` | Запустить ручной обратный отсчёт (`60s`, `5m`, `1h`) | `glowautorestart.admin` |
| `/gar cancel` | Отменить текущий обратный отсчёт | `glowautorestart.admin` |
| `/gar now` | Немедленно выполнить процедуру перезапуска | `glowautorestart.admin` |
| `/gar reload` | Перезагрузить конфигурацию и сообщения | `glowautorestart.admin` |
| `/gar help` | Показать список доступных команд | `glowautorestart.use` |

Алиасы команды: `/autorestart`, `/gar`.

## Конфигурация

### `config.yml`

```yaml
config-version: 1

schedule:
  mode: FIXED_TIMES
  fixed-times:
    - "00:00"
    - "06:00"
    - "12:00"
    - "18:00"
  timezone: UTC
  interval-seconds: 21600

notification:
  countdown-milestones:
    - 86400
    - 43200
    - 21600
    - 10800
    - 7200
    - 3600
    - 1800
    - 900
    - 600
    - 300
    - 180
    - 120
    - 60
    - 30
    - 15
    - 10
    - 5
    - 4
    - 3
    - 2
    - 1

bossbar:
  enabled: true
  color: YELLOW
  style: SOLID
  visible-seconds: 300

execution:
  kick-players: true
  restart-command: restart
  pre-restart-commands:
    - save-all
```

### `messages.yml`

Все тексты, префиксы, звуки и оформление настраиваются в `messages.yml`.
